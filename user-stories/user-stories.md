# 📘 User Stories for Airbnb Clone Backend

## 👤 User

- **Registration**  
  As a User, I want to register an account so that I can access the platform and book properties.

- **Login**  
  As a User, I want to log in to my account so that I can manage my bookings and profile.

- **Profile Management**  
  As a User, I want to update my personal information so that my profile stays current.

- **Search and Filter Properties**  
  As a User, I want to search and filter available properties so that I can find a suitable place to book.

- **Booking Creation**  
  As a User, I want to book a property so that I can reserve it for my stay.

- **Cancel Booking**  
  As a User, I want to cancel my booking if my plans change.

- **View Booking Status**  
  As a User, I want to view the status of my bookings so that I can stay informed.

- **Payments**  
  As a User, I want to pay for my bookings securely using the platform.

---

## 🧑‍💼 Host

- **Registration**  
  As a Host, I want to register an account so that I can list my property.

- **Login**  
  As a Host, I want to log in to my account to manage listings and reservations.

- **Profile Management**  
  As a Host, I want to manage my profile to maintain a trustworthy presence on the platform.

- **Property Listing**  
  As a Host, I want to add new properties to the platform so that users can book them.

- **Edit/Delete Listing**  
  As a Host, I want to edit or delete my property listings as needed.

- **Booking Status**  
  As a Host, I want to see booking requests and statuses for my properties.

- **Payments**  
  As a Host, I want to receive payments for bookings made on my properties.

---

## 🛠️ Admin

- **Login**  
  As an Admin, I want to log in to the system to manage users, hosts, and listings.

- **Manage Users and Hosts**  
  As an Admin, I want to view and manage all users and hosts to ensure platform safety.

- **Manage Listings**  
  As an Admin, I want to monitor and remove inappropriate or inactive property listings.

- **Oversee Payments**  
  As an Admin, I want to review and resolve any payment-related issues.
